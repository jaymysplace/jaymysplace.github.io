When this was on Neocities:

I followed the lovely guide here. I have no idea why but my Macbook really wanted to use an old version of Ruby, so I followed this guide to get it to upgrade to a more recent version

I use Visual Studio Code to write stuff. Then I use the Terminal in Visual Studio Code and type npx @11ty/eleventy --serve. In theory I don't need to add the --serve bit, but that starts up a local web server where I can preview the finished files.

Once the newly-made static files look ok, I go back to the Terminal and press Ctrl+C to stop Eleventy, then type neocities push _site/. which uploads everything in the _site directory (ie all of the files that Eleventy just made)

But now it's on GitHub!

I still use Visual Studio Code to write the stuff, and still does the npx @11ty/eleventy bit to get eleventy to make the actual html pages. Then I go on GitHub desktop and commit the changes from there. I have no idea how to do from the GitHub part from the terminal yet. I don't even know if I'd want to because I think I'd have to change directory and that's an extra step, and I can guarantee I'd forget to do it
