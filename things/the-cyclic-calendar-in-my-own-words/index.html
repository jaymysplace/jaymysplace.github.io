The real, (messy!) calendar has 12 months, each of which has an inconsistent number of days, an inconsistent number of weeks and different start and finish days.

Cyclic planning fixes it like this:

7 days in a week multiplied by 52 weeks in a year gives us 364 days in a year. A day or two short, but that's fixable.

52 weeks divided into 12 months doesn't quite work. We get 4 weeks per month, with a remainder of 4 weeks.

Each month is now exactly 4 weeks long. Because of this consistency, we can now have consistent start days (Mondays for me).

Monthly comparisons become easier because you don't need to account for variations in length, number of weekends etc.

Week numbering is now more intuitive. Rather than weeks 1-52 you can now call them, say, April Week 3.

Add those four 'remainder' weeks to the end of each quarter. Call them 'reset' weeks. March, June, September and December are all followed by a Reset Week. These weeks don't belong to any particular month, so use them to review, reset and re-orient.

This system assumes 364 days in a year: to stay in step, add a 'leap week' (an extra Reset Week!) every 6-ish years. This goes at the end of December, the same as a 'week 53' in the ISO 8601 standard.
